# Zara Sales Analysis
![alt text](ZARA.gif)
This project focuses on analyzing Zara's sales data to uncover trends and insights. The analysis is performed using Python, leveraging data manipulation and visualization libraries.

## Project Overview

The goal of this project is to analyze Zara's sales data to:
- Understand the impact of promotions on total sales.
- Identify trends and patterns in sales performance.
- Provide actionable insights for decision-making.




## Dataset

The dataset (`zara.csv`) contains the following key columns:
- **Promotion**: Type of promotion applied.
- **Total**: Total sales amount.
- **Terms**: Sales terms or categories.

## Tools and Libraries

The following Python libraries are used in this project:
- `pandas` for data manipulation.
- `seaborn` and `matplotlib` for data visualization.
- `numpy` for numerical operations.



## Conclusion

This project provides valuable insights into Zara's sales performance, helping to identify effective promotions and high-performing categories. These insights can guide strategic decision-making to optimize sales and revenue.
